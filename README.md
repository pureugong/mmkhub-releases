# mmkhub releases

Downloads for **mmkhub**, the command-line tool for your
[Magic Meal Kits Hub](https://hub.magicmealkits.com). Only release files live
here: the binaries for macOS, Linux and Windows, their `SHA256SUMS`, a cosign
signature, and the install scripts.

Not the Magic Meal Kits CLI (`mmk`, npm `@magic-meal-kits/cli`); that is a
different program.

How to install: https://docs-hub.magicmealkits.com/cli

No release has been published yet.
